همچنین نقطه‌های پویا عرض یکسان دارند، صفحه‌بندی کلیکی دکمهٔ واقعی با type=button دارد، کنترل صفحه‌کلید به اسلایدر دارای فوکوس محدود شده، فلش RTL اصلاح شده و وضعیت locked/disabled و ارتفاع برابر کارت‌ها استایل مشخص دارند. تصاویر وردپرس با API attachment تولید می‌شوند و حالت نسبت خودکار تصویر height:auto دارد.

در مرور منبع رسمی المنتور مشخص شد `get_settings_for_display()` می‌تواند تنظیمات دستگاهی را در بعضی حالت‌های duplication کنار بگذارد. برای کنترل‌های اجرایی responsive، `frontend_available` ثبت شد. برای تشخیص خاموش کردن صریح فلش‌ها از مقدار خالی پیش‌فرض المنتور، تنظیمات خام ذخیره‌شده نیز در حل دستگاه‌ها لحاظ می‌شوند.

- جداسازی منبع داده، حل responsive و قالب HTML؛ تست و workflow CI؛ مجوز GPL و مجوز MIT کتابخانه؛ ابزار ZIP با allowlist فایل‌ها.

## آزمون و محدودیت اعتبار

`npm test` شامل guardهای راه‌اندازی افزونه، آزمون‌های PHP با جایگزین‌های API، نبود ووکامرس و تست مرورگر headless با کتابخانهٔ واقعی Swiper است. خروجی نهایی تعداد بررسی‌ها را چاپ می‌کند. تصاویر و markup مرورگر از renderer PHP افزونه می‌آیند؛ برای تصاویر fixture از SVG آزمایشی استفاده می‌شود.

آخرین اجرا: **۳۷ بررسی PHP، ۷۶ بررسی مرورگری، سه سناریوی راه‌اندازی و سناریوی نبود ووکامرس همگی موفق بودند**. مرورگر Chromium `154.0.8037.95` بود. بررسی‌های مرورگر شامل کشیدن واقعی ماوس، غیرفعال کردن drag، لمس افقی، اسکرول عمودی لمس، توقف پس از چرخ ماوس و بازیابی focusability پس از نمایش container پنهان است. فایل MO نیز با parser مستقل GNU gettext در Python خوانده و تمام ۲۰۸ ترجمه تأیید شدند.

بررسی‌های PHP در محیط محلی PHP ۸٫۵٫۷ انجام شده‌اند. workflow برای PHP ۷٫۴، ۸٫۳ و ۸٫۵ تعریف شده ولی اجرای CI راه‌دور در این کار انجام نشده است. بررسی نحوی، `git diff --check` و محتوای ZIP نیز جداگانه کنترل می‌شوند.

**وردپرس کامل، دیتابیس ووکامرس و ویرایشگر المنتور در این محیط اجرا نشده‌اند.** بررسی رسمی APIها و جایگزین‌های آزمون، اجرای واقعی query، invalidation کش فروشگاه، مالیات و ارز، افزونه‌های شخصی‌سازی قیمت، ذخیرهٔ کنترل‌ها در editor یا سازگاری همهٔ نسخه‌ها/قالب‌ها را اثبات نمی‌کند. انتشار عمومی باید پس از ماتریس ادغام گزارش اولیه و نصب از ZIP روی محیط آزمایشی انجام شود.

لمس در Chromium شبیه‌سازی می‌شود؛ نتیجه جای آزمایش موبایل واقعی، Safari/iOS، pinch zoom و صفحه‌خوان را نمی‌گیرد. hover شدید و سایهٔ بزرگ، tabs/popups، delay/minify و کش کامل صفحه هنوز به آزمون روی سایت واقعی نیاز دارند. گزینهٔ «Tested up to» قدیمی از readme حذف شد تا برای این نسخه ادعای تأییدنشده ثبت نشود.
