# Security

Use the latest published release. Older releases may not receive separate fixes.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/sanyzrn/DbsProductSlider/security/advisories/new). Include affected versions, reproduction steps, impact and a minimal example. Please avoid posting exploit details, credentials or customer data in public issues.

Product page and support: [dbsstudio.ir/nexa-slider](https://dbsstudio.ir/nexa-slider).

Reports are reviewed by the maintainer. This project does not promise a fixed response time.
